# N01D Terminal Wiki

Welcome to **N01D Terminal** — a modern terminal emulator with tabs, split panes, and security features.

## Features

- GPU-accelerated rendering
- Tabbed interface with split panes
- Built-in SSH manager
- Custom themes (NullSec dark themes included)
- Configurable keybindings
- Unicode and ligature support

## Quick Start

```bash
git clone https://github.com/bad-antics/n01d-term
cd n01d-term
cargo build --release
./target/release/n01d-term
```
